# Generated Simulink Models

This directory contains the latest generated `.slx` baselines. Rebuild the
integrated model on the installed MATLAB release so the bridge ports and
diagnostic logging match the current source.

Run `run_all_tests` or the two builder functions to create:

- `Water_Treatment_Plant.slx`
- `Pressure_Controller_Test.slx`
- `Concentration_Controller_Test.slx`
- `Water_Treatment_Plant_OpenPLC_v0_4.slx`

Use `BUILD_OPENPLC_INTEGRATION` before the Stage 5 live test.
